实现与可视化

PyTorch 2.15 / CPU Adam · lr 0.03 二元交叉熵 300 轮
2 输入 → 2 sigmoid 隐藏 → 1 输出9 个可学习参数
01 / 任务

XOR：一条直线分不开的四个点

单层感知器的边界永远是一条直线，而异或的两类点正处在对角位置，所以任何直线都会同时切到两类。第 15 节给出的解法是加一个隐藏层：先把输入组合成中间特征，再由输出层合并。作业要做的，正是实现这个网络的参数学习过程并可视化。

(0, 0)目标 T = 0
(0, 1)目标 T = 1
(1, 0)目标 T = 1
(1, 1)目标 T = 0
网络结构：2-2-1
相邻层全连接。隐藏层用 sigmoid 激活，输出层先产生原始分数（logit），再经 sigmoid 转成 0～1 的概率。
学习参数一共 9 个
W 是输入到隐藏层的 2×2 权重（4 个），bhidden 是 2 个隐藏偏置，v 是隐藏到输出的 2×1 权重（2 个），boutput 是 1 个输出偏置。训练要调整的就是这 9 个数。

04 / 演化

参数不是一起动的：谁在长，谁在缩

把每 10 轮的参数快照连起来，可以看到权重与偏置各自的形状。W 的对角元素一路变大，非对角元素一路变负；两个隐藏偏置持续变小，输出层权重持续变大、输出偏置持续变小。

隐藏层权重 W 的四个元素
W₁₁、W₂₂ 变大，W₁₂、W₂₁ 变负，两个隐藏单元因此对相反的两个输入方向敏感。
偏置与输出层参数
b₁、b₂ 一起变负，v₁、v₂ 一起变大，boutput 变负，四个样本的分数被推离 0.5。

隐藏层把 XOR 变成了可分问题

07 / 实现

PyTorch 实现：五步完成一次参数更新

下面这段代码就是本页数据的来源。它和教材里的示例结构一致：手动写出前向计算、二元交叉熵损失、loss.backward() 求梯度，再由 Adam 更新参数。

mlp_xor.pyPyTorch 2.15 · CPU
import torch
import torch.nn.functional as F
torch.set_default_dtype(torch.float64)

# ① 张量：4 个样本，每个样本 2 个输入
x = torch.tensor([[0.,0.], [0.,1.], [1.,0.], [1.,1.]])
target = torch.tensor([[0.], [1.], [1.], [0.]])

# ② 模型参数：W、v 是连接权重，b 是偏置
W = torch.nn.Parameter(torch.tensor([[2., -2.], [-2., 2.]]))
b_hidden = torch.nn.Parameter(torch.tensor([-1., -1.]))
v = torch.nn.Parameter(torch.tensor([[3.], [3.]]))
b_output = torch.nn.Parameter(torch.tensor([-2.5]))
parameters = [W, b_hidden, v, b_output]
optimizer = torch.optim.Adam(parameters, lr=0.03)

for epoch in range(1, 301):
    optimizer.zero_grad(set_to_none=True)          # 清空上一轮梯度
    hidden = torch.sigmoid(x @ W + b_hidden)       # 隐藏层
    logits = hidden @ v + b_output                 # 输出层原始分数
    # ③ 损失：比较原始分数与正确答案
    loss = F.binary_cross_entropy_with_logits(logits, target)
    # ④ 反向传播：求每个参数对损失的影响
    loss.backward()
    # ⑤ 参数更新：Adam 读取梯度并改变参数
    optimizer.step()

hidden = torch.sigmoid(x @ W + b_hidden)
prob = torch.sigmoid(hidden @ v + b_output)
print((prob >= 0.5).int().flatten().tolist())

求梯度 ≠ 更新参数

loss.backward() 只把梯度写进各参数的 .grad；真正改变参数的是 optimizer.step()。

sigmoid 把分数压到 0～1

隐藏层用 sigmoid 产生中间特征，输出层再用 sigmoid 把 logit 转成概率，0.5 是分类阈值。

交叉熵配 logits 更稳

binary_cross_entropy_with_logits 把 sigmoid 与对数合在一起算，避免概率接近 0 或 1 时的数值问题。

整批训练

四个样本一次送入，损失取平均，因此每轮只有一次前向与一次反向，参数更新 300 次。

08 / 结论

这次实验看到了什么

  • 9 个参数就能改变能力边界。输入到隐藏的 4 个权重、2 个隐藏偏置、2 个输出权重和 1 个输出偏置，共同决定了决策边界的形状；单层感知器缺少隐藏层，因此只能画直线。
  • 参数的学习有方向，不是随机试探。反向传播给出损失对每个参数的偏导，Adam 按梯度方向更新，W 的对角元素变大、非对角元素变负，都是这个方向的结果。
  • 决策边界是参数的结果，不是预先设计的。训练前边界近似直线，训练后弯曲，是 9 个参数同步变化在输入平面上的投影。
  • 可视化让“学习”可观察。损失曲线、参数曲线、决策边界热力图和隐藏空间轨迹，分别对应训练的不同侧面；只看最终准确率，会漏掉过程。
